# Future Scope & Roadmap

### 1. IoT Sensor Integration
Live data feeds from soil sensors and weather stations to provide predictive warnings about disease-conducive environments.

### 2. Multi-Crop Support
Expanding the model architectures to support potatoes, grapes, and other high-value crops.

### 3. Edge Inference Mobile App
A lightweight mobile application that can perform diagnosis offline using ONNX or LiteRT.

### 4. Community Disease Tracking
Anonymous, location-based reporting to build real-time heatmaps of disease outbreaks at a regional level.
